# B3-1 동료 평가용 캡처 목록

이 문서는 필요한 증빙 화면과 가림 기준만 정의한다. 실제 파일이 없는 스크린샷을 새로 만들거나 꾸미지 않는다.

## 캡처할 화면

1. 외부 브라우저에서 http://13.125.211.95/#/terms 를 열어 기술용어사전 화면이 보이는 장면
2. EC2 콘솔의 `b3-1-web` 인스턴스 상태, 인스턴스 ID, public IPv4 및 IMDSv2 Required 설정
3. VPC 콘솔의 `b3-1-vpc`, `b3-1-public-subnet`, `b3-1-igw`와 각 리소스 ID·CIDR·연결 상태
4. `b3-1-public-rt`의 `0.0.0.0/0 → IGW` 경로 및 Public Subnet 명시 연결
5. `b3-1-web-sg`의 HTTP 80 공개 규칙과 SSH 22의 제한된 `/32` 규칙
6. EC2 내부 터미널의 `nginx -t` 성공 및 `curl -I http://localhost` HTTP 200 결과
7. 기준선에서 `npm run build` 후 `dist`가 생성된 빌드 결과

## 캡처 전 가릴 정보

- AWS 결제수단, 주소, 전화번호, MFA 정보, 로그인 이메일·사용자 이름, 세션 토큰
- SSH 개인키 파일명 외의 파일 경로·내용, 키 지문을 포함한 비밀값, API key 및 credential
- 콘솔 화면에 함께 보일 수 있는 다른 프로젝트·계정·리소스 정보
- SSH 규칙의 작업자 공인 IP처럼 개인 식별 또는 위치 추정에 사용될 수 있는 정보

계정 선택 메뉴, 브라우저 프로필, 알림·확장 프로그램 팝업도 캡처 전에 닫거나 가린다. 화면을 수정해 사실과 다르게 보이게 하지 않으며, 필요한 경우 민감한 부분만 마스킹한 원본의 사실 관계를 유지한다.
