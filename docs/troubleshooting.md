## 준비 단계 실제 관찰: 빌드의 큰 JS 청크 경고

- 환경: 2026-10-14, 기준선 5ada699c, Node v24.19.0 / npm 11.9.0.
- 재현: `npm ci` 후 `npm run build`.
- 관찰: 빌드 종료 코드 0, dist 생성. Vite가 일부 청크 500 kB 초과 경고 출력.
- 판단/조치: 배포 실패가 아닌 성능 경고다. 기능 동결에 따라 코드 분할 수정 없이 보존한다.
- 증빙: `evidence/build.log`.
